# jp-letters-lua

![jp-letters-lua 試作版 v0.4.0の紹介画像。マシュマロのお便りをOBSに表示し、まとめて取り込み・ページ送り・スクロール・表示前プレビューに対応。](docs/images/jp-letters-v0.4.0-banner.png)

マシュマロなどのお便りを準備して、OBSの配信画面に表示するツールです。

ブラウザの操作画面に本文を貼り付け、プレビューで見た目を確認してからOBSに表示できます。お便りを表示している間も、次のお便りを編集できます。

- 受信箱を丸ごとコピーし、お便りの本文を確認・編集してからまとめて登録できます。
- お便りを一覧に保存し、管理用のメモを付けて配信前に準備できます。ブラウザやOBSを閉じた後も、保存した準備を再開できます。
- フォント・文字の大きさ・カードの色・余白を調整できます。
- 「マシュマロ向け」プリセットでは、マシュマロ向けの色と外側の余白だけをまとめて設定できます。下中央には、利用者が用意した画像を表示できます。
- 長いお便りはページ送りや手動スクロールで読み進められます。

**[試作版 v0.4.1 をダウンロードする（ZIP）](https://github.com/hekiruligames/jp-letters-lua/releases/download/v0.4.1/jp-letters-0.4.1.zip)**

> 「マシュマロ向け」プリセットと下中央のアイコンは開発中です。上のv0.4.1 ZIPにはまだ含まれていません。

配信に表示されるお便りカードの例です。

![白いカードに日本語のお便りを表示した例](docs/images/output-v0.3.3.png)

マシュマロの非公式ツールです。自分が受信した本文や、コピーした受信箱の内容を貼り付けて使います。テキストファイル・JSONの取り込みにも対応しています。受信箱へのログインや、お便りの自動取得には対応していません。

## はじめて使う：OBSにお便りを表示するまで

OBS 30.2以降を用意してください。お便りを入力する操作画面は、OBSと同じPCのChrome・Edge・Safariなどで開きます。PythonやNode.jsの追加インストールは不要です。

Windows・macOSで同じZIPを使う設計の試作版です。LinuxのOBSとChromiumで検証していますが、Windows・macOSのOBS実機での検証はまだ行っていません。

### 1. ZIPを展開し、フォルダごと保管する

上のリンクからZIPをダウンロードして展開します。展開した `jp-letters-0.4.1` フォルダを、使い続ける場所に置いてください。たとえば「ドキュメント」の中に保管できます。

フォルダ内では、次のファイルとフォルダを一緒に保管します。

```text
jp-letters-0.4.1/
├── jp-letters.lua
├── runtime/
└── web/
```

ほかの説明書なども、そのまま残してください。OBSに登録した後にフォルダを移動・削除すると、OBSから読み込めなくなります。

### 2. OBSにスクリプトを追加する

OBSを開き、メニューの「ツール → スクリプト」を選びます。その画面の「＋」を押して、手順1で保管した `jp-letters.lua` を選びます。

### 3. シーンにお便りのソースを追加する

お便りを表示したいシーンを選び、OBSの「ソース」欄の「＋」を押します。

「**日本語お便りテキスト（マシュマロ向け）**」を選び、名前を付けて作成してください。

この時点では、お便りはまだ表示されません。手順5で表示ボタンを押すと、OBSのプレビューに現れます。

### 4. お便りの操作画面を開く

ソースのプロパティで「お便りの操作画面を開く」を押します。ブラウザで操作画面が開いたら、OBSのプロパティは「OK」で閉じてください。

プロパティを閉じてしまった場合は、OBSの「ソース」欄で、作成したソースの名前をダブルクリックすると開けます。

### 5. 本文を貼り付け、OBSに表示する

ブラウザの操作画面で「お便りの本文」に、表示したい文章を貼り付けます。まずは次の文章で試せます。

```text
いつも配信を楽しく見ています！
最近おすすめのゲームはありますか？
```

「表示前のプレビュー」で見た目を確認し、「**このお便りを配信に表示**」を押してください。OBSのプレビューに文章が表示されたら、導入は完了です。配信を開始せずに確認できます。

表示位置と大きさは、OBSのプレビュー上で調整できます。

配信前に本文や見た目を整えておきたい場合は、[準備の保存と再開](#配信前に準備してあとで続きを使う)の手順を参照してください。

## マシュマロ向けの見た目にする（開発中）

操作画面の「表示の設定」で「マシュマロ向け」を選ぶと、外側を `#F3969A`、カードを白、文字を黒にし、文字の輪郭を外します。外側の余白は上・右・左を16px、下を64pxにします。

このプリセットは、マシュマロ向け表示に必要な設定だけを変更します。フォント、文字サイズ、行間、左右・上下の配置、角の丸み、カード内の余白、ページ番号、表示方式などは、その時点の設定を保ちます。

白いカード内の「マシュマロ」は、設定の「マシュマロ表示と下中央のアイコン」で表示・非表示を切り替えられます。表示するとカード下端から約8pxの位置に出ます。別のサービス向けに使う場合は、このチェックを外せます。

新しいソースの初期値は、文字サイズ32px、外側の余白16px、左揃え・上揃えです。ほかの初期値は従来の設定を維持しています。

### 下中央に画像を表示する

「マシュマロ表示と下中央のアイコン」で「画像を選択」を押し、PNG・JPEG・WebP・GIFの画像を選びます。1枚128KB以内です。選んだ画像は設定欄に32pxのプレビューを表示し、OBSでは縦横比を保って下中央に表示します。画像はOBSの保存データと「ファイルに保存」で作るJSONにも含めます。読み込めない画像は表示しません。

jp-lettersには、マシュマロ公式のロゴ画像を同梱していません。公式ロゴを使う場合は、利用者自身でマシュマロ公式の[「ロゴ画像の利用について」](https://help.marshmallow-qa.com/%E3%83%AD%E3%82%B4%E7%94%BB%E5%83%8F%E3%81%AE%E5%88%A9%E7%94%A8%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6-66e2538617c946001d347fd3)を確認し、公式ページから取得した画像を指定してください。jp-lettersからロゴを自動取得する機能もありません。

## 受信箱のお便りをまとめて準備する（0.4.0で追加）

取り込みは、**マシュマロでコピー → jp-lettersに貼り付け → 内容を確認して登録** の順に進めます。コピーした内容からお便りの本文を取り出す機能です。URLだけを貼り付けて取り込む機能はありません。

### 1. マシュマロの受信箱をコピーする

マシュマロで「受信箱 → もらったメッセージ → 未確認」を開きます。個別のお便りはクリックせず、一覧を表示したままにしてください。

一覧の外にある灰色の余白をクリックしてから、ページ全体をコピーします。

| 使っているPC | キーボード操作 |
| --- | --- |
| Mac | ⌘Aで全選択 → ⌘Cでコピー |
| Windows | Ctrl＋Aで全選択 → Ctrl＋Cでコピー |

お知らせやメニューが一緒にコピーされても、そのままで構いません。まだ読み込まれていないお便りはコピーに入らないため、取り込みたいお便りが一覧に表示されているか確認してください。

### 2. jp-lettersに貼り付ける

jp-lettersの操作画面に戻り、左側の「受信箱から取り込む」を押します。コピーした内容を貼り付け、「内容を確認」へ進んでください。

### 3. 本文を確認して一覧に登録する

お便りごとに分かれた候補の本文・改行・件数を確認します。必要なら本文を編集し、取り込みたいものにチェックしてください。「重複以外を選ぶ」でまとめて選ぶこともできます。

「○件を一覧に登録」を押すとOBSへ保存します。保存が終わると確認画面が閉じ、一覧から配信の準備を続けられます。

登録前の候補は保存されないため、確認の途中でブラウザを閉じると消えます。

![コピーした受信箱から2件のお便りを取り出し、本文を確認して登録する画面](docs/images/inbox-safari-sample-v0.4.0.png)

判別できない形式では原文を残します。不要な部分を削り、必要に応じて「カーソル位置で分ける」でお便りを分けてください。[取り込みの詳しい手順](letters/README.md#お便りの登録と取り込み)も参照できます。

Safariでコピーした未確認一覧の実データ2件で、本文の抽出を確認しました。Mac・WindowsのOBS実機と、Safari上での操作画面の確認は継続中です。

## 配信中のお便りを操作する

操作画面には、配信中のお便りを操作する場所と、次のお便りを準備する場所があります。

| 場所 | できること | OBSの表示への反映 |
| --- | --- | --- |
| 上部の「配信画面を操作」 | 表示中のお便りのページ送り・スクロール | 操作するとすぐ反映します。 |
| 「表示前のプレビュー」と本文・表示設定 | 次に表示するお便りの編集と確認 | 準備中の編集だけでは配信の表示は変わりません。「このお便りを配信に表示」を押すと反映します。 |

長文を表示したら、上部の「配信中の表示方式」で「ページ送り」か「スクロール」を選びます。その近くのボタンやスライダーで、配信に出ている文章を読み進めてください。表示方式を切り替えると先頭に戻ります。

お便りを画面から消すときは、上部の「配信から非表示」を押します。

![お便りの一覧、配信画面の操作、表示前のプレビューが並ぶ操作画面](docs/images/operator-v0.3.3.png)

## 配信前に準備して、あとで続きを使う

本文・管理用のメモ・表示設定は、編集するたびにOBSへ自動保存します。すぐに配信へ表示する必要はありません。

![操作画面の上部にある「準備の保存・読み込み」。OBSへの保存状況と、ファイルを保存・読み込みするボタンを確認できます。](docs/images/preparation-save-load-v0.4.1.png)

### 準備を保存して操作画面を閉じる

1. お便りの本文や管理用のメモを入力し、表示設定を整えます。
2. お便りを左側の一覧にも登録したい場合は、本文の下の「一覧に保存」を押します。
3. 画面上部の「準備の保存・読み込み」で「**OBSに保存済み**」を確認してから、ブラウザを閉じてください。

一覧にまだ登録していない下書きも、自動保存されます。

### 後日、準備を再開する

1. OBSを開き、準備に使ったシーンとお便りのソースを選びます。
2. ソースの名前をダブルクリックしてプロパティを開き、「お便りの操作画面を開く」を押します。
3. 操作画面が開いたら、OBSのプロパティは「OK」で閉じてください。

保存したお便りや設定が操作画面に戻るので、そのまま準備を続けられます。

### ファイルで保管する・別のPCで使う

配信ごとに内容を保管したい場合や、別のPCで使いたい場合は、画面上部のボタンを使います。

| ボタン | できること |
| --- | --- |
| ファイルに保存 | お便りの一覧・入力中の下書き・表示設定・選んだアイコン画像・操作画面の配色を、1つのJSONファイルにまとめてダウンロードします。 |
| ファイルから読み込み | 保存したJSONファイルを選び、確認画面で読み込みを確定します。現在のお便り・下書き・表示設定・アイコン画像・操作画面の配色を、選んだファイルの内容に置き換えます。 |

読み込み後は、配信への表示がいったん非表示になります。プレビューで内容を確認してから「このお便りを配信に表示」を押してください。

ファイル名には保存した日時が付きます。保存先はブラウザの設定によります。OBSに保存できていない場合も、「ファイルに保存」で画面に残っている入力を保管できます。

保存・削除・フォント設定などの詳しい操作は、[使い方ガイド](letters/README.md#使い方)にまとめています。

## 旧版を使っている方へ

更新する前にバックアップを書き出し、**OBSを終了してください**。その後、既存フォルダの `jp-letters.lua` と `runtime`・`web` を、新しいZIPのファイルでまとめて上書きします。

0.2.0・0.3.0では、OBSを起動したままスクリプトを削除・再読み込みすると、OBSが終了する不具合があります。更新はOBSを終了してから行ってください。[旧版からの更新手順](letters/README.md#旧版から更新する)

## 0.4.1の改善

画面上部に **「準備の保存・読み込み」** を追加しました。OBSへの自動保存の状況と **「ファイルに保存」「ファイルから読み込み」** が、メニューを開かずに見えるようになりました。ファイルには入力中の下書きも含め、日時付きの名前で保存します。

[使い方と検証の記録](docs/validation-v0.4.1.md)

## 0.4.0の改善

コピーした受信箱と、区切って貼り付けた本文を、確認・編集・選択してから一括登録できるようにしました。判別できない形式では原文を保持します。配信中の表示を保ち、追加を1回で取り消せます。

[使い方と検証の記録](docs/validation-v0.4.0.md)

## 0.3.3の改善

一覧下の **「まとめて削除」** で、選んだお便り・紹介済み・一覧のすべてを削除できます。確認画面で件数と本文を見てから実行し、配信中の表示と表示設定は保ちます。**「一覧の操作を戻す」1回** で一括削除の全件を戻せます。

[使い方と検証の記録](docs/validation-v0.3.3.md)

## 0.3.2の改善

上部を **「配信画面を操作」** のパネルにし、表示中のお便り・ページ・スクロール位置を見分けやすくしました。表示方式は配信操作とプレビューの近くに置いています。

- 配信中の操作はOBSへすぐ反映します。方式を変えると、そのお便りだけを先頭へ戻します。
- 表示前プレビューは次のお便りの確認用です。「配信は変わりません」と明記し、読む位置と設定を独立して保ちます。

[改善と検証の記録](docs/validation-v0.3.2.md)

## 0.3.0からの機能

- フォントの一覧・検索・プレビューの即時反映
- 「一覧に保存」「非表示」「配信に表示」の操作とOSごとのキー表記
- 不透明度100%のスライダー、表示設定の初期化と3つの配色
- 枠960×540を維持し、720p・1080p・OBSキャンバスのボタンを追加
- 短文を縮め、長文は最大高さにする自動調整
- ページ方式に加え、全文を手動でスクロールして読むモード
- 現行ブルーに加え4つのパステル配色・カスタム・全設定バックアップ

自分が受信した本文の再利用については公式ヘルプに根拠があります。URLの自動取得の許諾と公式APIはまだ確認できておらず、[Issue #8](https://github.com/hekiruligames/jp-letters-lua/issues/8)へ調査結果を残します。

Safariの追加フォント制限に対応するため、選んだ書体をPC内だけでWebフォントとして読み込みます。埋め込みが制限された書体等は通常のPC内フォント表示へ戻し、案内を表示します。フォントのファイルは配布物やバックアップに同梱しません。

## 開発

- `letters/jp-letters.lua`: OBSソースと設定保存・ホットキー
- `letters/runtime/http.lua`: PC内の操作画面への接続
- `letters/web/`: 操作画面と日本語テキスト描画
- `tests/`: OBS LuaとChromiumの検証
- `tools/package-letters.py`: 配布ZIPの生成

ReleaseへのZIP添付は、GitHub Actionsの **Attach release ZIP** からタグと検証済みSHA-256を指定して実行します。ジョブ用の認証で添付し、ダウンロードしたファイルまで照合します。[公開担当者向けの手順](docs/release-attachment.md)。

GPL-2.0-or-later。ソースは配布物にも同梱します。
