# 返答用メモ #34（2026-11-26）

利用者から管理画面preview.5について「多分大丈夫」と報告。管理画面の基本操作は実機で暫定確認、全機能およびドラッグのCIは未合格。別ブランチで返答用メモを追加し、preview.5を維持する。

返答用メモ（preview.6）：プレビュー直下に配信者の返答・話す要点を書ける欄を追加。管理画面の新規作成・編集からも入力でき、管理画面の検索対象にも含まれます。お便りごとに最大4,000文字、既存の一覧項目では入力と同時に自動保存します。未登録の下書きも自動保存し、本文の一覧登録時にメモを引き継ぎます。旧版のバックアップはメモなしで読み込めます。メモは配信カードや表示中のスナップショットには含まれませんが、OBSの保存データ・バックアップJSONには含まれます。操作画面自体を画面キャプチャする場合には注意してください。

## 設計
- 保存形式version 1を維持し、items/draftに任意のreplyNoteを追加。空欄は省略し旧データと同じ構造を保つ。
- 選択・保存・新規・削除・取り消し・管理画面編集と連動。liveにメモは入れない。表示側は既存のlive描画を利用する。メモはローカル保存データであり、暗号化された秘密情報という意味ではない。
- 管理画面のドラッグは移動先の枠を変形させないようにし、dropEffectを設定。実ブラウザの再検証は必要。
- プレビュー直下の欄の高さは84px、縦方向に調整できる。

## 検証
既存E2Eにメモの入力・管理画面から編集・切り替え・再読み込み・JSON書き出し・削除・配信表示への非混入を追加。ドラッグも再検証する。CI結果とMac実機の操作感は未確認。
