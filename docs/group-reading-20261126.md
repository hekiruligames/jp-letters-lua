# グループ表示・手元の読み上げ改善 #35（2026-11-26）

preview.7に対する実機レビューを受けた修正。グループは多くのお便りが届いたことを画面で表現するためにも使う。小さくなるカードとは別に、手元で全件を読み、返答メモを確認できるようにする。preview.7はそのまま残す。

グループ表示の改善（preview.8）：2〜16件を選択してグループ化できます。自動グリッドは件数に応じて2〜4列、縦・横並びも選択可能。小さいカードは縮小して全体を見せるため、多数表示時は手元のプレビュー下にある全件の原文を読んでください。グループの全件について本文・個別の返答用メモを表示順に確認でき、グループ共通の返答用メモも入力できます。本文編集ボタンで個別に編集できます。共通・個別メモは配信カードに出ず、保存・バックアップに含まれます。左ペインと管理画面に緑の「組1」「組2」等を表示します。グループの番号は編集・順番変更でも維持され、旧グループには読み込み時に番号が付きます。同一のお便りは複数のグループに登録できません。最大16件は試作上の制限であり、多数カードの文字を配信画面で読めることを保証するものではありません。

## 仕様判断・制限
- 上限16件、自動グリッド2〜4列としたのは今回の試作上の判断。全件の文字可読性より全体のカード提示を重視する用途に対応。縦・横配置では件数が多いと特に小さくなる。共通メモを追加する判断も行った。
- グループ番号は既存の番号を保存・維持する。新規作成時は現存する最大番号+1を割り当てる（末尾番号を削除すると再利用され得る）。グループ名は任意。旧データは正規化で番号を補完する。
- グループの本文・個別メモを手元で全件表示。単体表示は従来どおり。グループ編集中の変更は表示中スナップショットに影響しない。
- 保存容量の上限は従来どおり。自由配置や個別カードサイズは未実装。
- preview.7のCIは以前の複数ドラッグ移動で失敗（run 45743515070）。今回のテストはドラッグ元と先を同一ビューポート内に置いてポインタ操作を確認するよう変更した。結果は未確認。後続のグループE2Eを追加したがCI・Mac実機確認は必要。

## 追加案：カード列のスクロール

縦・横スクロール（preview.8）：グループの配置から「縦スクロール」「横スクロール」を選べます。全体を縮める配置とは異なり、通常のカードの幅・文字サイズを維持した固定枠の中をカード列が移動します。縦は短文に合わせた高さ、横は通常の枠幅です。長文はページを順につなげます。スクロールバーで自由に移動でき、前後ボタンは縦なら約一画面（10%重複）、横なら次のカードまたはページの先頭へ、約280msで滑らかに移動します。プレビューと配信は独立しています。「ループ」を有効にするとブラウザ操作で末尾から次へ押して先頭へ戻れます（逆方向も同様）。初期状態ではオフで、設定は画面を開いている間だけ保持します。自動連続スクロールや継ぎ目のない無限ループではありません。OBSホットキーは同じ移動幅で端まで進みます。

横スクロールのカード間隔は12px。縦スクロールの10%重複は読み飛ばし防止のため。スライダーとは別に前後ボタンを操作できる。E2Eに固定枠、両軸、末尾への到達、プレビューと配信の独立、ループの確認を追加した。ループの操作は自動移動ではなく端から反対端へ戻る手動操作。CI・実機は未確認。
