# お便り管理画面（#33）試作 2026-11-26

土台は利用者のレイアウト確認済みの0.5.2-preview.3（PR #37、CI run 45659826944成功）。別ブランチで開発し、配信UIのレイアウトを維持する。正式版v0.5.1と旧試作は未変更。

**お便り管理（0.5.2-preview.5）**：左のお便り一覧の「お便り管理」を押すと、全文・管理用メモ（メモが空なら本文の冒頭）・紹介済み状態・順番を広い画面で確認できます。チェックで複数選択し、上下・先頭・末尾・移動後の先頭位置（1始まり）へまとめて移動できます。選択した項目の相対順序は維持します。選択済みのハンドルを別の項目へドラッグすると、その項目の直前へまとめて移動します。未選択のハンドルをドラッグするとその1件を選択します。変更はOBSへ自動保存し、表示中の内容と準備中の本文は維持します。「元に戻す」で直前の一覧操作を取り消せます。閉じても変更は保存されます。配信操作に戻るにはボタンまたはEscを使います。

## 検証
Chromium E2Eで複数選択・先頭/末尾/指定位置・上下・取り消し・ドラッグ、順序・紹介済み状態・配信中スナップショットと下書き維持、390px画面の管理ダイアログ、Escで配信表示が変わらないことを追加確認する。結果はActionsで確認。Mac Safari実機の操作感は未確認。

## 対象外
返答用メモ #34、グループ化 #35、関連画像 #36、保留中のアーカイブは今回含めない。複数本文の同時編集は対象外。左ペインの機能は管理画面にも配置し、左ペイン側は変更しない。

## 管理画面の機能拡張（preview.5）

管理画面では並べ替えに加え、新規登録、各行の本文・管理用メモ編集、配信の準備（表示は変えない）、検索、未紹介/紹介済みの絞り込み、選択項目の紹介状態変更、確認付き削除、受信箱・まとめて貼り付け・テキスト/JSON取り込み、バックアップ保存/読み込みも利用できます。検索・絞り込みを変更すると選択を解除し、表示中の項目だけを一括選択します。移動位置は全一覧での番号です。バックアップの読み込みは既存仕様どおり確認後に一覧と設定を置き換え、配信を非表示にします。それ以外の管理操作は配信中のスナップショットを保持します。

追加E2E：新規登録・編集・検索・絞り込み・紹介状態の一括変更・確認付き削除・取り消し・取り込みダイアログ・ファイル選択・バックアップのダウンロード。CIとMac実機確認は未完了。
