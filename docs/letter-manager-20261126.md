**お便り管理（0.5.2-preview.4）**：左のお便り一覧の「お便り管理」を押すと、全文・管理用メモ（メモが空なら本文の冒頭）・紹介済み状態・順番を広い画面で確認できます。チェックで複数選択し、上下・先頭・末尾・移動後の先頭位置（1始まり）へまとめて移動できます。選択した項目の相対順序は維持します。選択済みのハンドルを別の項目へドラッグすると、その項目の直前へまとめて移動します。未選択のハンドルをドラッグするとその1件を選択します。変更はOBSへ自動保存し、表示中の内容と準備中の本文は維持します。「元に戻す」で直前の一覧操作を取り消せます。閉じても変更は保存されます。配信操作に戻るにはボタンまたはEscを使います。

Chromium E2Eで複数選択・先頭/末尾/指定位置・上下・取り消し・ドラッグ、順序・紹介済み状態・配信中スナップショットと下書き維持、390px画面の管理ダイアログ、Escで配信表示が変わらないことを追加確認する。結果はActionsで確認。Mac Safari実機の操作感は未確認。
