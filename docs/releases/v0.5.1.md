## 変更点

マシュマロ向けの白いカード下部に薄く表示される「マシュマロ」の文字を、自由に変更できるようになりました。

- 「表示の設定 → カード下部の文字・アイコン → カード下部に表示する文字」から、好きな文字を入力できます（最大40文字）。
- 初期値は従来どおり「マシュマロ」。空欄にすると表示されず、チェックボックスでの表示切り替えもできます。
- 入力結果は表示前プレビューですぐに確認でき、配信中の表示は「このお便りを配信に表示」を押すまで変わりません。
- 設定はOBSの自動保存とJSONバックアップに含まれ、以前の保存データも引き続き読み込めます。
- 以前からある画像アイコン機能や、配信の一覧・保存機能も維持しています。

## ダウンロード・更新

下のAssetsから`jp-letters-0.5.1.zip`をダウンロードして展開してください。必要なLua・HTML・JS・CSSと利用ガイドを含みます。実行時にPythonやNode.jsの追加インストールは不要です。

更新する場合は、**まず操作画面の「ファイルに保存」でバックアップし、OBSを終了**してから`jp-letters.lua`・`runtime`・`web`を一緒に上書きしてください。OBS起動後はソースのプロパティから操作画面を開き直してください。

## 検証

GitHub Actions上でLinuxの実OBS LuaJIT＋ChromiumによるテストとZIPの整合性検証に成功した成果物を配布します。macOS・SafariとWindowsのv0.5.1実機検証はまだ完了していません。詳細は[検証条件と記録](https://github.com/hekiruligames/jp-letters-lua/blob/v0.5.1/docs/validation-v0.5.1.md)。

このツールはマシュマロ非公式です。サービスへログインしたり、受信箱を自動取得したりしません。
