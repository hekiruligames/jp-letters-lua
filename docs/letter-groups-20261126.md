# グループ化と複数カード表示 #35（2026-11-26）

基準版0.5.2-preview.6を保持し、別ブランチで試作する。

グループ化（preview.7）：お便り管理画面で未グループ化の2〜4件にチェックを入れ「グループ化」。名前・カードの順番・縦並び/横並び/2列グリッドを設定して保存します。管理画面または左一覧のグループボタンから準備し、プレビュー確認後に配信へ表示します。元のお便りは残り、単独表示も可能です。グループ解除しても本文やメモは消えません。配信中の内容は準備画面の変更では変わらず、グループを紹介済みにすると全メンバーが紹介済みになります。複数カードは固定高さ・ページ送りで、同じページ番号を進めます（短いカードは最終ページを保持）。枠が狭い場合は幅・高さを増やすか配置を変更してください。グループ時の装飾アイコンは表示せず、本文編集・返答メモ欄は先頭のお便りに対応します。各お便りのメモは個別に残ります。自由位置・個別サイズ・5件以上は今回対象外。

## 設計・保存
- 旧version 1の状態に任意のgroups、draft.groupId、live.groupCards等を追加。OBSのオブジェクト配列でグループ構成を保存し、配信時の順序・配置・本文を独立スナップショットとして保存。返答メモを描画データに入れない。
- 同一お便りは1グループに所属。個別表示は引き続き可能。削除で残り1件以下のグループは解除。グループ構成はバックアップに含まれる。旧版へ戻す際は新しいグループ情報が失われ得るためバックアップを残す。
- グループ用描画は既存カード描画を再利用し、全体寸法を固定する。各カードの最小領域は320×180px。自由配置は未実装。
