# 日本語お便りテキスト 0.2.0

マシュマロ読み配信などのお便りを、準備・プレビュー・配信への表示・ページ切り替えまで扱うOBS用ソースです。LuaとOBS内蔵のブラウザ描画を組み合わせています。同じ配布フォルダをWindowsとmacOSで利用する設計です。

## 導入

1. ZIPを展開し、`jp-letters-0.2.0` フォルダを使い続ける場所に置きます。`runtime` と `web` フォルダも一緒に保管します。
2. OBSの **「ツール → スクリプト → ＋」** で、このフォルダの **`jp-letters.lua`** を選びます。
3. OBSのソース追加から **「日本語お便りテキスト（マシュマロ向け）」** を選びます。
4. ソースのプロパティで **「お便りの操作画面を開く」** を押します。操作画面が開いたら、OBSのプロパティは **「OK」** で閉じます。
5. 操作画面にマシュマロの本文を貼り付け、プレビューを確認して **「このお便りを配信に表示」** を押します。

OBSのLuaJITとブラウザソースを使用します。Python・Node.jsや別のプラグインのインストールは不要です。OBS 30.2以降を対象にしています。操作画面は現在のChrome・Edge・Safari等で開いてください。

初回は本文を登録するまで出力が透明です。設定を確認しやすいよう、背景の見えるシーンでソースを追加してください。

操作画面はこのPC内のローカル接続で開きます。OBSを起動し、このスクリプトを有効にしている間に利用できます。OBSを再起動したら、ソースのプロパティまたは「ツール → スクリプト」のボタンから操作画面を開き直してください。ブラウザ画面の更新ボタンで再開できない場合も、このボタンから開き直せます。

## 使い方

### 準備中と表示中を分ける

- 本文の入力・編集、一覧の選択、フォントや余白の調整は **準備中** のお便りに反映します。
- **「配信に表示」** を押すと、その時点の本文と見た目をまとめて反映します。
- 別のお便りを選ぶことや一覧から削除することだけでは、表示中の本文は入れ替わりません。
- 次のお便りを選ぶ際、入力済みの下書きは一覧に保存します。文字が空の下書きは追加しません。

管理用のメモは通常、操作画面の一覧だけに表示します。「管理用のメモも配信に表示する」をオンにすると、カードにも表示します。

### 長文とページ切り替え

文字を際限なく小さくする代わりに、指定したフォントと行間のままページに分けます。画面の枠はお便りが変わっても同じ大きさです。

右下のプレビューの矢印は **準備中のページ**、上部の矢印は **配信に表示中のページ** を切り替えます。「紹介済みにして次を準備」は表示を消して紹介済みを記録し、次のお便りを準備します。すでに別のお便りを準備している場合は、その準備を保ちます。

改行や段落を保持し、表示幅に合わせて折り返します。CSSの日本語向け改行と、ページ境界での基本的な禁則処理を使用します。絵文字の結合や濁点を途中で切らないようにします。枠や余白の設定で1行も置けない場合は、操作画面で調整を案内します。

### 余白と見た目

既定の枠は **960 × 540px**、外側の透明な余白は **四辺40px**、文字は **48px・行間1.5倍** です。初期書体はWindowsで `Yu Gothic`、macOSで `YuGothic`（游ゴシック）を指定します。フォント名はインストール済みの書体に変更できます。

「外側の透明な余白」は、ソースの固定した枠の内側で、文字やカードの周囲に取る透明な領域です。ソースへ影やグローを追加する際に使います。十分な領域が必要な場合は枠の大きさも増やしてください。「カード内の余白」は背景カードと本文の間隔です。

プリセットは「カード」「透過」「やわらかい」の3種類です。文字色・輪郭・配置、カードの色・不透明度・丸みも調整できます。透過のプリセットは、他の配信素材と合わせて文字だけを表示する用途に向いています。

### お便りの登録と取り込み

1件ずつ貼り付けるほか、「取り込み・バックアップ」からまとめて登録できます。

- **まとめて貼り付け / テキストファイル**：お便りの間に、単独の行で `---` または `///` を入れます。本文中の空行は段落として残ります。UTF-8のテキストを使用してください。
- **JSONから追加**：`[{"title":"メモ","text":"本文"}]`、文字列の配列、またはこのツールのバックアップから、お便りを一覧へ追加します。
- **バックアップ復元**：お便りと表示設定を置き換え、表示を非表示にします。内容はプレビューで確認してから表示してください。

`samples/お便りサンプル.txt` に、そのまま取り込める例があります。最大300件、1件の本文は12,000文字までです。一覧・下書き・表示中の本文・設定を合わせたデータは約800KBまでとし、取り込むファイルは1MBまでです。大きな一覧はバックアップを書き出し、配信ごとに分けて管理してください。

現在の版は **マシュマロ本文の貼り付け・テキストファイル・JSON** に対応します。受信箱へのログイン、自動取得、URLだけからの取得、画像の文字認識は含みません。

### 並べ替え、紹介済み、取り消し

一覧を選択して「上へ・下へ」を押すか、左端のハンドルでドラッグします。検索と「未紹介・紹介済み」の絞り込みを使用できます。

「一覧の操作を戻す」で、削除・並べ替え・紹介済みなどの直近15回の一覧操作を戻せます。この操作でも配信に表示中の本文は入れ替わりません。操作画面を開き直すと、取り消しの履歴はリセットされます。

### キーボードとOBSホットキー

操作画面が手前にあるとき：

| キー | 操作 |
| --- | --- |
| Alt + Enter（MacではOption + Return） | 準備中のお便りを表示 |
| Alt + ← / → | 表示中の前 / 次のページ |
| Esc | 非表示 |

OBSの **「設定 → ホットキー」** にも、各ソースの「次のページ」「前のページ」「非表示」が追加されます。操作画面が手前にないときの操作には、こちらにキーを割り当てます。

## 保存と接続

お便りの一覧、下書き、紹介済み、表示設定はOBSのソース設定として保持します。変更後はOBSのシーン保存も要求します。「OBSに保存済み」を確認してから操作画面を閉じてください。別のOBSやPCへ移す場合はバックアップJSONを書き出すと取り込めます。

複数のソースは、それぞれ別の一覧を持ちます。操作画面上部で操作対象を選べます。同じソースの操作画面を複数開いて変更が競合した場合、後からの変更で上書きせず、入力をその画面に残して案内します。

接続できない場合は、OBSが起動中でスクリプトが有効か確認し、OBSのボタンから操作画面を開き直します。「キャンセル」でソースのプロパティを閉じると、OBSが開く前の設定へ戻すため、操作画面を開いた後はプロパティを「OK」で閉じます。

## 検証状況

Linuxのlibobs 30.2.3の実際のLuaJIT実行環境で、ソース登録、設定の保存・復元、ホットキー、表示の準備完了待ち、子ソースの後始末を検証しています。HTMLの日本語描画と操作画面は実際のChromiumで検証しています。ネイティブ側の検証ではブラウザソースをテスト用の描画ソースで代用しており、Linux上で実際のOBSブラウザソースを通した検証ではありません。

**macOS・WindowsのOBS実機での動作確認は、この版ではまだ行っていません。** Mac・Windowsで同じ配布ファイルを使用できる構成ですが、OSごとの接続・ブラウザソースとの連携は実機確認が必要です。OSやフォントのバージョンで文字幅・ページ数が変わることもあります。

検証コードはプロジェクトの `tests/letters-integration.cpp`、`tests/letters-e2e.mjs`、`tests/run-letters-tests.py` です。配布ZIPには結果とファイルのハッシュを `validation.json` に記録します。配布物の使用に開発用テストのインストールは不要です。

## ソースとライセンス

GPL-2.0-or-later。`jp-letters.lua` がOBSへのソース登録、`runtime/http.lua` がローカル接続、`web` フォルダが操作画面と文字の描画です。接続は `127.0.0.1` に限定し、起動ごとの接続キーを使います。スクリプトを外すと接続も終了します。
